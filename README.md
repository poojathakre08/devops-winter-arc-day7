# 🚀 DevOps Winter Arc — Day 07
## Git, GitHub & Production Troubleshooting

A hands-on DevOps project combining **Git/GitHub version control, Linux/WSL, branching, Pull Requests, `.gitignore`, Nginx reverse proxy, application troubleshooting, and production incident management**.

---

## 📌 Project Overview

This project was created as part of the **90-Day DevOps Winter Arc — Day 07**.

The objective was to practice a real-world DevOps workflow starting from local development and version control, continuing through GitHub collaboration, and ending with a simulated production incident.

The project demonstrates:

- Git configuration and repository management
- Working directory → staging area → commit workflow
- Git branching and merging
- `.gitignore`
- GitHub remote repositories
- SSH authentication
- Feature branches
- Pull Requests and code review
- Nginx reverse proxy
- Python test application
- HTTP 502 troubleshooting
- Root cause analysis
- Application recovery
- Production incident documentation

The complete project was performed using **WSL (Windows Subsystem for Linux)**.
